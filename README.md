# 技换 SkillSwap ⇄
产品Demo：https://github.com/Aalan020912/MeiTuan_skillExchangePlatform.git
> 用你的技能，换一个新世界。

「技换 SkillSwap」是一个技能互换社区平台 demo：发布「我能教的」与「我想学的」，由双向智能匹配算法为你找到正好互补的交换伙伴，并通过交换契约、信用分、徽章与互评机制保障交换质量。

纯前端单页应用，无需注册、无需后端，打开即玩（内置种子数据：8 名用户、21 条技能、2 条交换请求、3 条评价）。

## 功能特性

- **首页**：Hero 双 CTA、三步流程说明、8 大热门分类标签云、精选技能卡片、平台数据看板（数字滚动动画）
- **技能广场**：teach 技能卡片流、关键词搜索（250ms 防抖）、分类筛选、空态引导
- **发布技能**：「我能教 + 我想学」双栏表单、必填校验、熟练程度滑块、付费请教开关、提交 confetti 庆祝并自动跳转匹配页
- **智能匹配**：双向匹配算法（完美匹配 100 分 / 单向 60 分 / 同分类兜底 45 分 + 信用加权）、匹配度环形动画、按分数排序、重复发起自动置灰
- **交换契约**：契约模态框（形式 / 周期 / 留言 / 爽约扣分提示），请求状态机 `pending → accepted → completed / rejected / cancelled`
- **信用与徽章**：完成交换 +10、收到 ≥4 星好评 +5、爽约 -15；徽章墙（🌱 新手村 / 🤝 靠谱交换者 / 🏆 技能达人）
- **我的**：资料卡与徽章进度、技能管理（可删除）、交换请求双 Tab（我收到的 / 我发起的）、收到的评价
- **全局体验**：Hash 路由、桌面玻璃拟态导航 + 移动端底部 Tab（含发布 FAB 与消息角标）、Toast、Confetti、用户主页模态框、`prefers-reduced-motion` 动画降级

## 技术栈

- 原生 HTML / CSS / JavaScript（零框架、零构建）
- Hash 路由实现 SPA 页面切换
- `localStorage` 本地持久化（存储键：`skillswap_v1`）
- SVG 环形进度、CSS 动画与玻璃拟态设计

## 快速开始

无需任何依赖与构建步骤：

1. 直接用浏览器打开 `index.html`；或
2. 使用任意静态服务器，例如：
   ```bash
   npx serve .
   # 或
   python -m http.server 8080
   ```

如需重置演示数据，清除浏览器 localStorage 中的 `skillswap_v1` 键即可。

## 项目结构

